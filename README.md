# GREEN-API Тестовое

Тестовое задание на должность «Фронтенд-разработчик React».
Сделано для WhatsApp.

## Запуск

```bash
npm ci
npm run dev
```

Приложение откроется на http://localhost:5173.

## Стек
- Шаблонизатор **Vite**
- **React 19 + TypeScript** (strict)
- **Redux Toolkit**
- **React Router**
- **react-hook-form + zod**
- **СSS**
